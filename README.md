## تشغيل ديريكت - 3 دقايق:

1. حمل الملفات:
   - src/app/page.tsx
   - src/app/layout.tsx
   - src/app/globals.css
   - tailwind.config.js
   - package.json

2. ثبت:
   npm install
   npm run dev

3. حل http://localhost:3000
